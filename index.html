動画の位置情報、タグの確認と削除の手順

何があったか

ffmpeg-cookbook.comの解説記事。動画ファイルに埋め込まれた位置情報などのタグを確認・削除する方法を扱っている。確認はffprobeの`-show_format -show_streams -show_chapters`やExifToolの`-a -ee -G1 -s`で行い、削除は`ffmpeg -map_metadata -1 -map_metadata:s -1 -map_chapters -1 -c copy`で再エンコードせずに書き出す方法が示されている。架空の位置情報や独自タグを付けた動画での検証では、「タグを一括削除」を使うとMKVとMP4の両方でタグが残らなかったが、「既知の個人タグを削除」ではMKVで独自タグが残ったと報告されている。回転情報や映像データに埋め込まれた情報（H.264のSEIなど）は`-c copy`では消えないとも書かれている。

明日から試せること

動画のファイルに位置情報が残っていないか不安なときは、まずffprobeの`-show_format -show_streams -show_chapters`やExifToolの`-a -ee -G1 -s`でタグを確認し、`-map_metadata -1 -map_metadata:s -1 -map_chapters -1 -c copy`のコマンドで再エンコードせずに位置情報とチャプターを落として書き出せる。「タグを一括削除」の方が「既知の個人タグを削除」より確実にタグが残らないという違いも、使い分けの判断にそのまま使える。

メール添付の動画、容量を逆算して圧縮

何があったか

ffmpeg-cookbook.comの解説記事。メールに動画を添付して送るときの容量の抑え方を扱っている。個人用Gmailの添付上限は合計25MB、Outlookは条件により20MBや10MBとされ、上限から逆算してビットレートを決める式として「合計＝目標MB×8000÷秒数」「映像＝合計−音声」が示されている。ffmpegコマンド例として`ffmpeg -i input.mp4 -vcodec libx264 -crf 28 -preset slow -acodec aac -b:a 96k output.mp4`でのCRF圧縮や、`-vf scale=-2:720`で解像度を720pに落とす方法、`-b:v 1000k`のように目標ビットレートを指定する2パスエンコードのコマンドも載っている。10秒・音声なしの動画で23.28MBから1.83MBまで縮んだ例も示されている。

明日から試せること

動画をメールに添付して送りたいときは、Gmailなら25MB・Outlookなら20MBや10MBという上限を踏まえて、「合計＝目標MB×8000÷秒数」の式で映像のビットレートを逆算してから、`-crf 28`や`-vf scale=-2:720`のコマンドで容量を抑えて書き出せる。

iPhone動画が開けない時の切り分け方

何があったか

ffmpeg-cookbook.comの解説記事。iPhoneで撮った動画がWindowsで再生できないときの原因の切り分け方を扱っている。iPhone本体で元動画を確認する→PCに動画全体をコピーし直して長さとファイルサイズを確認する→別のプレーヤーで試す、という順で切り分け、コーデックが原因の場合や横倒しになる場合、色が白っぽい場合など症状別の対処が示されている。変換コマンド例として`ffmpeg -i input.mov -map 0:v:0 -map "0:a:0?" -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -preset fast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart output.mp4`が載っている。拡張子を.movから.mp4に変えても中の映像形式は変わらない、10bitの映像がすべてHDRとは限らない、といった注意点も書かれている。

明日から試せること

iPhoneで撮った動画がパソコンで開けない・再生できないときは、iPhone本体で元動画を確認する→PCに動画全体をコピーし直す→別のプレーヤーで試す、の順で原因を切り分けてから、`ffmpeg -i input.mov -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -preset fast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart output.mp4`で変換すれば開けるようになる。
